# 房东模拟器 - 外置平板插件

为「房东模拟器Z5.20」角色卡打造的外置插件集合，整合手机系统与住户管理功能。

## 功能模块

| 模块 | 说明 |
|------|------|
| 手机增强插件 | 为 Abstract 外置手机添加壁纸、本地上传等增强功能 |
| 住户管理插件 | 浮窗式公寓管理面板（房源管理/住户动态/招租任务） |
| 自定义APP注入 | 手机主屏注入「招租APP」和「天眼监控APP」 |
| 壁纸库 | 10张真人美女壁纸，点击右上角图标切换 |
| 住户通讯录同步 | 自动将 MVU 租客列表同步到手机通讯录和住户群 |

## 安装方法

### 方式一：酒馆助手脚本引用（推荐）

1. 打开酒馆助手 → 扩展脚本 → 新建脚本
2. 脚本内容填写以下一行：

```javascript
import 'https://raw.githubusercontent.com/520ccb/landlord-tablet-plugin/main/index.js'
```

3. 保存并启用脚本
4. 同时需要安装「Abstract外置手机」脚本（手机主程序）

### 方式二：手动下载

下载 `index.js`，在酒馆助手中新建脚本并粘贴全部内容。

## 依赖

- 酒馆助手（Tauri / 浏览器版）
- Abstract 外置手机主程序
- MVU 变量更新插件

## 使用

- 点击输入框下方「手机」按钮打开手机浮窗
- 按 `Ctrl+Shift+C` 打开住户管理面板
- 手机「招租」APP 发布招租信息
- 手机「天眼」APP 开启万能监控

## 住户管理插件

- **首页**：公寓壁纸、公寓名称编辑、账户资金、快捷入口
- **房源管理**：单间/合租/整租/商铺 四分类，房间详情+租金
- **住户动态**：生活/美食/出行/美图 四频道，动态流
- **招租任务**：自定义招租要求+租金，住户申请入住
